# 레스토라럭스 (RestoraLuxe)

서울·인천·경기·부산 **동 1,232칸**과 지정 시군구 **152곳**으로 출장마사지·홈타이를
보내는 안내 사이트. 바깥 의존성 없이 Node 표준 라이브러리만 쓴다.

```
npm run regions   # /tmp/hjd.geojson → data/regions.json  (경계선 결 계산)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사 14종
npm run serve     # 로컬 미리보기
```

## 이 사이트가 재는 값 — 테두리의 결

경계 바깥 선을 이루는 꼭짓점을 차례로 훑으며 꺾이는 각을 재고, **5도를 넘게 꺾이는
자리에서 선을 끊어** 구간으로 묶는다. 그중 **250m 넘게 곧게 이어지는 구간**이 테두리
전체 길이에서 차지하는 몫이 '곧은 몫'이다. 함께 **가장 긴 직선 변**, **크게 꺾이는
모서리 수**, **테두리 1km에 찍힌 꼭짓점 수**를 낸다.

자로 그은 경계는 도로·철길·구획선을 따라간 선이라 길이 격자로 나고 번지가 순서대로
붙는다. 휜 경계는 물길이나 능선을 따라간 선이라 골목이 휘고 막다른 길이 잦다.

★1m 안에 겹쳐 찍힌 점은 하나로 묶는다. 그러지 않으면 원자료의 미세한 흔들림이
전부 '굽었다'로 읽혀 어느 동네나 비슷한 값이 나온다.
★꼭짓점마다 재면 네 점짜리 네모가 0%로 나온다 — 네 변이 전부 곧은데도. 구간으로
묶어야 사람이 보는 반듯함과 맞는다(`scripts/build-regions.mjs` 의 `edgeTexture`).

## 꼭 지키는 것

- **같은 주소 = 같은 HTML.** 무작위를 쓰지 않는다. 문장 고르기는 전부 md5 시드.
- **읍과 면은 쪽을 내지 않는다**(2026-10-13 지시). 시군구 쪽에 이름만 싣는다.
- 전화번호는 `hailBtn()` 안에서만 찍힌다. 버튼 라벨은 '예약 문의' 하나.
- 후기·체험담·별점·인물 사진 없음. 푸터에 AI 활용 고지.
- 설명문은 100자 안쪽. FAQ 질문은 `h3` 질문형(순번은 h3 밖).
- `data/lastmod.json` 을 **반드시 커밋한다.**

## 호스팅
